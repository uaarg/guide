# Software

This section contains documentation and tutorials for those working with the
UAARG code bases.

It is meant to be self-contained. It should link to or explain all concepts new
members need to be productive on our codebases. Larger concepts like Python
programming or CS theory are out of scope, but resources should still be linked
where possible.

Start by setting up all required tools in the [Getting
Started](./getting-started.md) chapter.
